# LinkedIn showcase draft

I built Market Lane, an Amazon-inspired full-stack shopping demo using React, Node.js, and Express.

The project includes product search, category filters, sorting, product details, favorites, and a persistent shopping bag. The Node.js backend validates quantities, calculates totals from server-owned prices, and saves demo orders to disk.

I also added API integration tests and a GitHub Actions workflow that builds and deploys a responsive frontend preview to GitHub Pages.

One useful distinction: GitHub Pages hosts the frontend preview. The complete checkout runs with the Node.js backend; the preview clearly labels that limitation.

Source: https://github.com/gim1203-hue/full-stack-project
Frontend preview: https://gim1203-hue.github.io/full-stack-project/

This is a portfolio demo with sample products and no real payments or fulfillment. Built with assistance from Codex.
