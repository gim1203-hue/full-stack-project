# Image captions and upload order

1. **Product catalog** — Browse an 80-product demo assortment with category filters, search, sorting, and load-more controls. Each category has 16 sample items.
2. **Product details** — React displays the selected product’s sample price, description, features, and add-to-bag action.
3. **Shopping assistant results** — Lane matches the customer’s product type and budget, shows catalog cards, and asks relevant questions about shopping needs.

These are actual screenshots of the public frontend preview. The repository also contains the Node.js/Express backend, which must be hosted separately for the public site to submit demo orders. The public assistant uses catalog rules; a model can be connected on the backend to generate shopping follow-up questions.
